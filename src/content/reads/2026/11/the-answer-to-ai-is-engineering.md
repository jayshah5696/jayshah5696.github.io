I'm not sold on the claim that we don't need most open-source libraries anymore, but the supply-chain case is worth weighing: small, well-specified code may be generated, while cryptography and other trusted-core code still need careful stewardship. I like the pivot from building faster to responding to incidents faster, especially the claim that optimizing response times can speed builds too; the Nix-and-agents framing makes this an engineering argument rather than another call to ship more code.
