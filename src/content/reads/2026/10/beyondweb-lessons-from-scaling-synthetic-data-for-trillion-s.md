I'd start with the finding that simple summarization can match generator-driven data like Cosmopedia, then compare it with the failure of naive continuations to beat repeated web data by much. I like that contrast because it points to the real lever: filling gaps in the training distribution, not just making more text. The 14-benchmark average is striking, though I'd want to see the per-benchmark spread before treating it as a broad win.
